# Per-PHP-Version Configuration Design

**Date:** 2026-04-15
**Status:** Approved

## Problem

Currently, PHP runtime settings (upload_max_filesize, memory_limit, etc.) are hardcoded in the php.ini generated during PHP installation. Users cannot easily adjust these settings per PHP version without manually editing the php.ini file.

## Solution

Allow configuring PHP runtime settings per PHP version in `chauffeur.yaml`, applied via `conf.d/limits.ini` in each PHP version's etc directory.

## Config Structure

```yaml
php:
  default_version: "8.3"
  versions:
    8.3:
      upload_max_filesize: "64M"
      post_max_size: "64M"
      memory_limit: "256M"
      max_execution_time: 300
      max_input_vars: 5000
    7.4:
      upload_max_filesize: "32M"
      post_max_size: "32M"
      memory_limit: "128M"
      max_execution_time: 120
      max_input_vars: 1000
```

## CLI Interface

```bash
# Show PHP version config
chauf config php 8.3

# Update a setting
chauf config php 8.3 upload_max_filesize 128M

# List all PHP version configs
chauf config php
```

## Implementation Details

### 1. Config Struct Changes

**workspace/config.go:**

```go
// PHPVersionConfig holds runtime settings for a specific PHP version.
type PHPVersionConfig struct {
    UploadMaxFilesize string
    PostMaxSize       string
    MemoryLimit       string
    MaxExecutionTime  int
    MaxInputVars      int
}

// Config.PHP extended:
type Config struct {
    PHP struct {
        DefaultVersion string
        Versions       map[string]PHPVersionConfig
    }
}
```

### 2. Default Values

```go
func DefaultPHPVersionConfig() PHPVersionConfig {
    return PHPVersionConfig{
        UploadMaxFilesize: "64M",
        PostMaxSize:       "64M",
        MemoryLimit:       "256M",
        MaxExecutionTime:  300,
        MaxInputVars:      5000,
    }
}
```

### 3. New CLI Command

**commands/config.go** - Add `configPHP` function:

```go
func RunConfig(args []string) error {
    // existing config handling...
    // Add: chauf config php <version> [key] [value]
}
```

### 4. Writing Settings to conf.d/limits.ini

**installers/php.go** - Add `WritePHPConfig(ver string, cfg PHPVersionConfig)`:

```go
func (p *PHPInstaller) WritePHPConfig(cfg workspace.PHPVersionConfig) error {
    confdDir := filepath.Join(p.InstallDir(), "etc", "conf.d")
    iniPath := filepath.Join(confdDir, "limits.ini")
    
    content := fmt.Sprintf(`; Auto-generated by chauf - edit via: chauf config php <version>
upload_max_filesize = %s
post_max_size = %s
memory_limit = %s
max_execution_time = %d
max_input_vars = %d
`, cfg.UploadMaxFilesize, cfg.PostMaxSize, cfg.MemoryLimit, cfg.MaxExecutionTime, cfg.MaxInputVars)
    
    return os.WriteFile(iniPath, []byte(content), 0644)
}
```

### 5. Call WritePHPConfig during PHP install

After `writePhpIni()`, call `WritePHPConfig(DefaultPHPVersionConfig())`.

### 6. Regenerate config after setting changes

When user runs `chauf config php <version> <key> <value>`, regenerate the limits.ini file.

## Files Affected

- `internal/workspace/config.go` - Extend Config struct, add parsing
- `internal/commands/config.go` - Add `configPHP` subcommand
- `internal/installers/php.go` - Add `WritePHPConfig` method
