# Systemd Integration

## Overview

Chauffeur V2 supports auto-start via **user-level systemd services** (`systemctl --user`). No root required. Services start automatically on user login.

This is a V2 new feature, not present in V1.

---

## Unit File Location

User systemd units live at:
```
~/.config/systemd/user/chauffeur-nginx.service
~/.config/systemd/user/chauffeur-php-fpm@.service  # template unit
```

---

## Nginx Unit File

Generated by `chauf autostart enable nginx`:

```ini
# ~/.config/systemd/user/chauffeur-nginx.service
[Unit]
Description=Chauffeur nginx
After=network.target

[Service]
Type=forking
PIDFile=%h/.chauffeur/nginx/logs/nginx.pid
ExecStart=%h/.chauffeur/nginx/bin/nginx -c %h/.chauffeur/nginx/etc/nginx.conf
ExecReload=/bin/kill -HUP $MAINPID
ExecStop=/bin/kill -QUIT $MAINPID
PrivateTmp=no
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=default.target
```

---

## PHP-FPM Template Unit File

Generated for shared pools (one instance per PHP version):

```ini
# ~/.config/systemd/user/chauffeur-php-fpm@.service
[Unit]
Description=Chauffeur PHP-FPM (%i)
After=chauffeur-nginx.service

[Service]
Type=forking
PIDFile=%h/.chauffeur/php/%i/runtime/php-fpm/php-fpm.pid
ExecStart=%h/.chauffeur/php/%i/bin/php-fpm --fpm-config %h/.chauffeur/php/%i/etc/php-fpm.conf --daemonize
ExecReload=/bin/kill -USR2 $MAINPID
ExecStop=/bin/kill -TERM $MAINPID
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=default.target
```

Enable for a specific PHP version:
```bash
systemctl --user enable chauffeur-php-fpm@8.3.service
```

## Commands

### `chauf autostart enable`

```bash
chauf autostart enable              # Enable nginx + all installed PHP versions
chauf autostart enable nginx        # Enable only nginx
chauf autostart enable php 8.3      # Enable PHP-FPM 8.3 only
```

**Flow**:
1. Write unit file to `~/.config/systemd/user/`
2. Run `systemctl --user daemon-reload`
3. Run `systemctl --user enable <unit>`
4. Run `systemctl --user start <unit>`

### `chauf autostart disable`

```bash
chauf autostart disable             # Disable all Chauffeur services
chauf autostart disable nginx       # Disable only nginx
chauf autostart disable php 8.3     # Disable PHP-FPM 8.3 only
```

**Flow**:
1. Run `systemctl --user stop <unit>`
2. Run `systemctl --user disable <unit>`
3. Optionally remove unit file

### `chauf autostart status`

```bash
chauf autostart status
```

**Output**:
```
Chauffeur Auto-Start Status

  nginx                ● active (running) since 2025-01-01 09:00
  php-fpm@8.3          ● active (running) since 2025-01-01 09:00
  php-fpm@8.1          ○ inactive (dead)
```

### `chauf autostart list`

Lists all Chauffeur systemd units and their enabled/disabled state.

## Lingering (Run Without Login Session)

For services to start on boot before any user login, lingering must be enabled:

```bash
loginctl enable-linger $USER
```

Chauffeur checks for lingering status in `chauf doctor` and suggests enabling it if the user wants services to start on boot, not just on login.

## Implementation Notes

```go
// internal/system/systemd.go

type SystemdManager struct {
    userConfigDir string  // ~/.config/systemd/user/
}

func (s *SystemdManager) WriteNginxUnit(ws *workspace.Workspace) error {
    tmpl := nginxUnitTemplate(ws)
    unitPath := filepath.Join(s.userConfigDir, "chauffeur-nginx.service")
    return os.WriteFile(unitPath, []byte(tmpl), 0644)
}

func (s *SystemdManager) EnableUnit(name string) error {
    if err := s.daemonReload(); err != nil {
        return err
    }
    return exec.Command("systemctl", "--user", "enable", "--now", name).Run()
}

func (s *SystemdManager) daemonReload() error {
    return exec.Command("systemctl", "--user", "daemon-reload").Run()
}

func (s *SystemdManager) IsActive(unit string) bool {
    err := exec.Command("systemctl", "--user", "is-active", "--quiet", unit).Run()
    return err == nil
}
```

## `chauf doctor` Systemd Checks

1. `systemctl --user` works: `systemctl --user status`
2. XDG_RUNTIME_DIR is set (required for `--user` systemd): `echo $XDG_RUNTIME_DIR`
3. For each enabled unit: `systemctl --user is-active <unit>`
4. Lingering enabled (if units are configured): `loginctl show-user $USER`
