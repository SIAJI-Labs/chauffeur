# PHP Integration

## Overview

Chauffeur compiles PHP from source for each supported version. Each version gets its own isolated directory under `~/.chauffeur/php/<version>/`. A PHP shim at `~/.chauffeur/bin/shims/php` routes to the correct version per project.

---

## Supported Versions

| Version | Status | Notes |
|---------|--------|-------|
| 8.4 | ✅ Full | Latest stable |
| 8.3 | ✅ Full | Default version |
| 8.2 | ✅ Full | |
| 8.1 | ✅ Full | |
| 8.0 | ⚠️ Legacy | Requires GD patching (`installers/php_legacy.go`) |
| 7.4 | ⚠️ Legacy | EOL. LibXML ≤ 2.11 required. Best-effort. |

## Build Configuration

```bash
./configure \
  --prefix=$HOME/.chauffeur/php/<version> \
  --enable-fpm \
  --with-fpm-user=$USER \
  --with-fpm-group=$USER \
  --enable-mysqlnd \
  --with-mysqli=mysqlnd \
  --with-pdo-mysql=mysqlnd \
  --with-openssl \
  --with-zlib \
  --with-bz2 \
  --with-curl \
  --enable-gd \
  --with-jpeg \
  --with-freetype \
  --with-png \
  --with-zip \
  --enable-bcmath \
  --enable-gmp \
  --with-readline \
  --with-libxml \
  --with-xsl \
  --with-sodium \
  --enable-opcache \
  --enable-exif \
  --enable-intl
```

Then:
```bash
make -j$(nproc)
make install
```

```

├── bin/
```

## PHP Shim

The shim at `~/.chauffeur/bin/shims/php` detects the current project's PHP version:

```bash
#!/bin/bash
# ~/.chauffeur/bin/shims/php

CHAUFFEUR_HOME="${CHAUFFEUR_HOME:-$HOME/.chauffeur}"

# Walk up directories to find .chauffeur-version or project config
DIR="$PWD"
while [[ "$DIR" != "/" ]]; do
    if [[ -f "$DIR/.chauffeur-version" ]]; then
        VERSION=$(cat "$DIR/.chauffeur-version")
        exec "$CHAUFFEUR_HOME/php/$VERSION/bin/php" "$@"
    fi
    DIR="$(dirname "$DIR")"
done

# Check project config by looking up workspace
# ... (Go binary handles complex lookup)

# Fallback: use default PHP version from workspace config
DEFAULT_VERSION=$(grep 'default_version' "$CHAUFFEUR_HOME/config/chauffeur.yaml" | awk '{print $2}' | tr -d '"')
exec "$CHAUFFEUR_HOME/php/$DEFAULT_VERSION/bin/php" "$@"
```

The actual shim is generated by the Go CLI during `chauf init` with proper error handling.

## OpenSSL Configuration

Each PHP version gets `etc/conf.d/openssl.ini` with distribution-aware CA paths:

```ini
[openssl]
openssl.cafile = /etc/ssl/certs/ca-certificates.crt
openssl.capath = /etc/ssl/certs
```

Distribution paths:
| Distro | cafile |
|--------|--------|
| Arch | `/etc/ssl/certs/ca-certificates.crt` |
| Debian/Ubuntu | `/etc/ssl/certs/ca-certificates.crt` |
| Fedora/RHEL | `/etc/pki/tls/certs/ca-bundle.crt` |

## PECL imagick Extension

Installed separately after PHP build:

1. Fetch latest stable tarball from PECL API: `https://pecl.php.net/get/imagick`
2. Extract and build with `phpize` + `configure` + `make install`
3. Add `extension=imagick.so` to `php.ini`

Override for offline installs:
```bash
CHAUFFEUR_IMAGICK_TARBALL=/path/to/imagick-3.7.0.tgz chauf install php 8.3
```

## Legacy PHP (7.4, 8.0)

Legacy PHP versions have additional constraints handled in `installers/php_legacy.go`:

**GD Extension** — API changed between PHP 7 and 8:
- PHP 7.4, 8.0: Use `--with-jpeg-dir`, `--with-png-dir` (old flags)
- PHP 8.1+: Use `--enable-gd`, `--with-jpeg`, `--with-freetype` (new flags)

**LibXML constraint**:
- PHP 7.4: Requires libxml2 ≤ 2.11 (2.12 has breaking API changes)
- `chauf doctor` warns if system libxml2 ≥ 2.12 when installing legacy PHP

**ImageMagick constraint**:
- PHP 7.4: imagick extension may not compile with ImageMagick 7.1+
- `chauf doctor` checks MagickWand version before legacy PHP builds

## PHP Process Management

```go
// internal/services/php_fpm.go

type PHPFPMService struct {
    version   string
    pidPath   string
    sockPath  string
    configPath string
    binaryPath string
}

func (p *PHPFPMService) Start() error {
    if p.IsRunning() {
        return nil  // idempotent
    }
    return exec.Command(p.binaryPath, "--fpm-config", p.configPath, "--daemonize").Run()
}

func (p *PHPFPMService) Stop() error {
    pid, err := p.readPID()
    if err != nil {
        return nil
    }
    return syscall.Kill(pid, syscall.SIGTERM)
}

func (p *PHPFPMService) Reload() error {
    pid, err := p.readPID()
    if err != nil {
        return p.Start()
    }
    return syscall.Kill(pid, syscall.SIGUSR2)  // graceful reload
}
```

## Version Isolation

`chauf php isolate <version>` writes a `.chauffeur-version` file in the project root:

```
/home/user/Projects/my-app/.chauffeur-version
```

Content: `8.1`

The PHP shim reads this file when walking up the directory tree. This is the same approach as `.ruby-version` and `.node-version`.

`chauf php use <version>` updates the global default in `~/.chauffeur/config/chauffeur.yaml`.

## Dependency Validation

Before compiling PHP, validate all required libraries exist:

```go
// internal/lib/deps.go
var PHPBuildDeps = []Dependency{
    {Name: "libzip", PkgConfig: "libzip"},
    {Name: "libjpeg", PkgConfig: "libjpeg"},
    {Name: "libpng", PkgConfig: "libpng"},
    {Name: "freetype2", PkgConfig: "freetype2"},
    {Name: "libxml-2.0", PkgConfig: "libxml-2.0"},
    {Name: "libcurl", PkgConfig: "libcurl"},
    {Name: "zlib", PkgConfig: "zlib"},
    {Name: "readline", PkgConfig: "readline"},
    {Name: "MagickWand", PkgConfig: "MagickWand"},
    {Name: "libsodium", PkgConfig: "libsodium"},
}
```

If any dependency is missing, abort with a list of missing libraries and the appropriate `pacman`/`apt`/`dnf` install command for the detected distribution.
