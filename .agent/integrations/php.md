# PHP Integration

## Overview

Chauffeur compiles PHP from source for each supported version. Each version gets its own isolated directory under `~/.chauffeur/php/<version>/`. A PHP shim at `~/.chauffeur/bin/shims/php` routes to the correct version per project.

## Build Configuration

```bash
./configure \
  --prefix=$HOME/.chauffeur/php/<version> \
  --enable-fpm \
  --with-fpm-user=$USER \
  --with-fpm-group=$USER \
  --enable-mysqlnd \
  --with-mysqli=mysqlnd \
  --with-pdo-mysql=mysqlnd \
  --with-pgsql \
  --with-pdo-pgsql \
  --with-openssl \
  --with-zlib \
  --with-bz2 \
  --with-curl \
  --enable-gd \
  --with-jpeg \
  --with-freetype \
  --with-png \
  --with-zip \
  --enable-bcmath \
  --enable-gmp \
  --with-readline \
  --with-libxml \
  --with-xsl \
  --with-sodium \
  --enable-opcache \
  --enable-exif \
  --enable-intl
```

Then:
```bash
make -j$(nproc)
make install
```

Native PostgreSQL prerequisite: the host system must provide PostgreSQL client development headers so `pg_config` and `libpq-fe.h` are available during configure. On Debian/Ubuntu install `libpq-dev`; on Fedora install `postgresql-devel`; on Arch install `postgresql-libs` (or the equivalent development package for your distro).

## PHP Shim

The shim at `~/.chauffeur/bin/shims/php` detects the current project's PHP version:

```bash
#!/bin/bash
# ~/.chauffeur/bin/shims/php

CHAUFFEUR_HOME="${CHAUFFEUR_HOME:-$HOME/.chauffeur}"

# Walk up directories to find .chauffeur-version or project config
DIR="$PWD"
while [[ "$DIR" != "/" ]]; do
    if [[ -f "$DIR/.chauffeur-version" ]]; then
        VERSION=$(cat "$DIR/.chauffeur-version")
        exec "$CHAUFFEUR_HOME/php/$VERSION/bin/php" "$@"
    fi
    DIR="$(dirname "$DIR")"
done

# Check project config by looking up workspace
# ... (Go binary handles complex lookup)

# Fallback: use default PHP version from workspace config
DEFAULT_VERSION=$(grep 'default_version' "$CHAUFFEUR_HOME/config/chauffeur.yaml" | awk '{print $2}' | tr -d '"')
exec "$CHAUFFEUR_HOME/php/$DEFAULT_VERSION/bin/php" "$@"
```

The actual shim is generated by the Go CLI during `chauf init` with proper error handling.

## OpenSSL Configuration

Each PHP version gets `etc/conf.d/openssl.ini` with distribution-aware CA paths:

```ini
[openssl]
openssl.cafile = /etc/ssl/certs/ca-certificates.crt
openssl.capath = /etc/ssl/certs
```

Distribution paths:
| Distro | cafile |
|--------|--------|
| Arch | `/etc/ssl/certs/ca-certificates.crt` |
| Debian/Ubuntu | `/etc/ssl/certs/ca-certificates.crt` |
| Fedora/RHEL | `/etc/pki/tls/certs/ca-bundle.crt` |

## PECL imagick Extension

Installed separately after PHP build:

1. Fetch latest stable tarball from PECL API: `https://pecl.php.net/get/imagick`
2. Extract and build with `phpize` + `configure` + `make install`
3. Add `extension=imagick.so` to `php.ini`

Override for offline installs:
```bash
CHAUFFEUR_IMAGICK_TARBALL=/path/to/imagick-3.7.0.tgz chauf install php 8.3
```

## Legacy PHP (7.4, 8.0)

Legacy PHP versions require additional source patches and compiler flags to build on modern Linux systems. All handled in `installers/php_legacy.go`.

### GCC 14 Compatibility

GCC 14 tightened C standard enforcement. PHP 7.4 and 8.0 use old-style `()` function pointer declarations that are now errors, not warnings. Chauffeur applies two fixes:

**CFLAGS** (set via `VendoredOpenSSLEnv`):
```
-Wno-deprecated-declarations -Wno-discarded-qualifiers -Wno-incompatible-pointer-types
```
`-Wno-incompatible-pointer-types` suppresses assignment-level errors when typed function pointers are passed to `void (*func_p)()` parameters.

**Source patches** applied by `ApplyLegacyPatches()`:

| Patch function | File(s) patched | What it fixes |
|----------------|-----------------|---------------|
| `patchLibXML` | `ext/libxml/libxml.c` | `ATTRIBUTE_UNUSED` macro, `xmlOutputBufferCreateFilenameDefault` guard, structured error handler cast |
| `patchOpenSSLExt` | `ext/openssl/openssl.c` | OpenSSL 3.x `EVP_PKEY_get0_RSA` + `RSA_SSLV23_PADDING` shims |
| `patchScanf` | `main/spprintf.c`, `main/snprintf.c`, `ext/standard/scanf.c` | `zend_long (*fn)()` typed to `(const char *, char **, int)` and casts updated |
| `patchGDCtx` | `ext/gd/gd_ctx.c` (7.4 only, absent in 8.0) | Explicit casts on all `(*func_p)(...)` call sites in `_php_image_output_ctx` |
| `patchGD` | `ext/gd/gd.c` | Explicit casts on all `(*func_p)` / `(*ioctx_func_p)` call sites in image create/output functions |

> **Note**: PHP 8.0 merged `gd_ctx.c` into `gd.c`. `patchGDCtx` skips gracefully when the file is absent.

### Vendored OpenSSL

PHP 7.4 and 8.0 are not compatible with OpenSSL 3.x on the build or runtime level. Chauffeur compiles OpenSSL 1.1.1w into `~/.chauffeur/cache/vendor-openssl-<version>/` and points the PHP build at it via `PKG_CONFIG_PATH` and `LD_LIBRARY_PATH`.

### GD Flags

PHP 8.0 has a different GD configure interface than 7.4; both differ from 8.1+:
- PHP 7.4, 8.1+: `--enable-gd --with-jpeg=/usr --with-freetype=/usr` (bundled in main build)
- PHP 8.0: GD built separately via `BuildGD80()` post-install

### LibXML

`patchLibXML` patches `ext/libxml/libxml.c` to handle libxml2 2.12's API changes (`xmlOutputBufferCreateFilenameDefault` removal, handler cast changes). No system version constraint is required.

## PHP Process Management

```go
// internal/services/php_fpm.go

type PHPFPMService struct {
    version   string
    pidPath   string
    sockPath  string
    configPath string
    binaryPath string
}

func (p *PHPFPMService) Start() error {
    if p.IsRunning() {
        return nil  // idempotent
    }
    return exec.Command(p.binaryPath, "--fpm-config", p.configPath, "--daemonize").Run()
}

func (p *PHPFPMService) Stop() error {
    pid, err := p.readPID()
    if err != nil {
        return nil
    }
    return syscall.Kill(pid, syscall.SIGTERM)
}

func (p *PHPFPMService) Reload() error {
    pid, err := p.readPID()
    if err != nil {
        return p.Start()
    }
    return syscall.Kill(pid, syscall.SIGUSR2)  // graceful reload
}
```

## Version Isolation

`chauf php isolate <version>` writes a `.chauffeur-version` file in the project root:

```
/home/user/Projects/my-app/.chauffeur-version
```

Content: `8.1`

The PHP shim reads this file when walking up the directory tree. This is the same approach as `.ruby-version` and `.node-version`.

`chauf php use <version>` updates the global default in `~/.chauffeur/config/chauffeur.yaml`.

## Dependency Validation

Before compiling PHP, validate all required libraries exist:

```go
// internal/lib/deps.go
var PHPBuildDeps = []Dependency{
    {Name: "libzip", PkgConfig: "libzip"},
    {Name: "libjpeg", PkgConfig: "libjpeg"},
    {Name: "libpng", PkgConfig: "libpng"},
    {Name: "freetype2", PkgConfig: "freetype2"},
    {Name: "libxml-2.0", PkgConfig: "libxml-2.0"},
    {Name: "libcurl", PkgConfig: "libcurl"},
    {Name: "zlib", PkgConfig: "zlib"},
    {Name: "readline", PkgConfig: "readline"},
    {Name: "MagickWand", PkgConfig: "MagickWand"},
    {Name: "libsodium", PkgConfig: "libsodium"},
}
```

If any dependency is missing, abort with a list of missing libraries and the appropriate `pacman`/`apt`/`dnf` install command for the detected distribution.
